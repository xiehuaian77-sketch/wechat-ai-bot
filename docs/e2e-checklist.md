# 真机验收清单

本文档提供 WeChat AI Bot 的真机验收流程，确保所有功能在生产环境中正常运行。

---

## 📱 验收环境

- **设备**：Windows PC + 微信 PC 客户端
- **网络**：稳定的互联网连接
- **测试账号**：至少 2 个微信号（Bot 号 + 用户号）

---

## ✅ 验收流程

### 阶段 1：环境检查

- [ ] Docker 已安装并运行
- [ ] 项目代码已克隆到本地
- [ ] `.env` 文件已配置
- [ ] 至少一个 API Key 已配置

### 阶段 2：服务启动

- [ ] `docker compose up -d` 执行成功
- [ ] 所有容器状态为 `healthy`
- [ ] `curl http://localhost:8000/health` 返回 `{"status": "healthy"}`
- [ ] ChromaDB 连接正常

### 阶段 3：微信连接

- [ ] ComWeChatRobot 已启动
- [ ] Bot 微信号已登录
- [ ] FastAPI 收到微信 Hook（检查日志）
- [ ] 消息解析正常（无乱码）

### 阶段 4：核心功能

#### 4.1 基础对话

- [ ] 用户发送"你好" → Bot 正常回复
- [ ] 多轮对话上下文正常（发送"刚才说的是什么" → 正常回复）
- [ ] SSE 流式输出正常（打字机效果）

#### 4.2 Battle Mode

- [ ] 发送 `@battle GPT-4 vs Claude-3.5-Sonnet：量子计算` → 双模型正常回复
- [ ] 投票功能正常
- [ ] 结果展示正常

#### 4.3 RAG 知识库

- [ ] 上传 PDF 文件 → 成功解析
- [ ] 提问 → 成功检索并回答
- [ ] 检索置信度显示正常

#### 4.4 工具调用

- [ ] 发送"今天北京天气怎么样" → 调用天气工具
- [ ] 发送"搜索 Python 教程" → 调用搜索工具
- [ ] 工具调用结果正常展示

#### 4.5 管理后台

- [ ] 访问 `/admin` → 管理后台正常显示
- [ ] 查看统计数据 → 数据正常
- [ ] Token 用量统计正常

### 阶段 5：异常处理

- [ ] 发送超大消息（>2000 字） → 正常截断或提示
- [ ] 发送图片（非 Bot 支持格式） → 正常提示
- [ ] API Key 失效 → 正常降级或提示
- [ ] Redis 断开 → 正常重连

### 阶段 6：性能测试

- [ ] 连续发送 20 条消息 → 无卡顿
- [ ] 并发 5 个用户对话 → 响应正常
- [ ] 内存使用稳定（无内存泄漏）
- [ ] API 响应时间 < 2s

### 阶段 7：安全测试

- [ ] 白名单用户可正常对话
- [ ] 非白名单用户被拒绝
- [ ] 限流功能正常（超过限制被拒绝）
- [ ] 日志无敏感信息泄露

### 阶段 8：兼容性测试

- [ ] Windows 10 正常
- [ ] Windows 11 正常
- [ ] 微信版本 3.x 正常
- [ ] ComWeChatRobot 版本正常
